## ¿Qué es Kaggle
Kaggle es la comunidad en línea y plataforma gratuita más grande del mundo para la ciencia de datos y el aprendizaje automático (machine learning), adquirida por Google en 2017. Ofrece competiciones para resolver problemas reales, miles de conjuntos de datos (datasets) públicos, cuadernos de trabajo (notebooks) en la nube y cursos gratuitos. 

### ¿Cómo podemos usarlo? 
Podemos usar `Kaggle` para:
* Descargar dataset
* Practicar análisis de datos
* Aplicar machine learning
* Participar en competencias
* Aprender viendo proyectos de otros

## Datasets 
**1. TMDB 5000 Movie Dataset**
¿Qué contine?

* Información de películas
* Género, presupuesto, ingresos
* Calificaciones y popularidad

Tipo de datos -> Datos estructurados (tablas con filas y columnas)

**2. Dogs vs Cats**
¿Qué contine?

* Carpetas con imágenes (`.jp`, `.png`)
* No están en tablas
* Se usan para reconocimiento visual

Tipo de datos -> Datos no estructurados

**3. House Prices Dataset**
¿Qué contine?

* Precios de casas
* Tamaño, ubicación, número de habitaciones
* Año de construcción

Tipo de datos -> Datos estructurados (tablas con filas y columnas)

## Dataset de interés -> Dogs vs Cats
### ¿Qué información contiene?
* Miles de imágenes de perros y gatos
* Cada imagen pertenece a una categoría:
    - Perro
    - Gato
* Los datos están organizados en carpetas, no en tablas
* Formatos comunes: .jpg o .png
* Dataset de tipo -> no estructurado
